# UI Motion Polish

## Goal

Refine the interface visually and improve interaction quality without changing the overall product direction.

## Focus areas

- visual hierarchy
- spacing rhythm
- typography clarity
- contrast and readability
- component consistency
- hover states
- focus states
- transitions
- subtle animations
- interaction feedback
- perceived smoothness
- responsive polish

## Good animation principles

- animation should support clarity, not decoration
- keep motion subtle and intentional
- prioritize smooth transitions
- use motion to reinforce hover, focus, reveal, and navigation
- preserve accessibility and readability
- avoid excessive movement
- avoid trendy animation that weakens professionalism

## Preferred improvements

- clearer CTA states
- better hover feedback on cards and links
- subtle image or card lift on hover
- clean fade/slide reveal for sections when appropriate
- smoother button transitions
- improved spacing and alignment
- stronger visual grouping between sections

## Avoid

- large dramatic motion
- autoplay effects that distract from content
- excessive parallax
- looping decorative animation
- flashy effects that reduce credibility
- motion that harms accessibility
- unnecessary JS if CSS can solve it

## Output

When using this skill, provide:

1. what visual or interaction problems were found
2. what should be improved
3. which changes should be made in HTML, CSS, or JS
4. why those changes improve the portfolio
5. any accessibility considerations

## Implementation rules

- prefer CSS transitions and transforms when possible
- keep code clean and reusable
- preserve mobile usability
- make hover and focus states clearly visible
- keep the final result aligned with a premium UX portfolio
